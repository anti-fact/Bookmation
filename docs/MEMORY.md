## 長期的に維持するプロダクト像

- プロダクト名は `Bookmation` である。元企画では仮称であるため、公開名称を確定するまでは名称変更の可能性がある。
- 最初の対象はChrome拡張機能である。
- Bookmationは、ブラウザ既存の「ブックマーク + フォルダ」を直接拡張するのではなく、拡張機能専用のブックマーク集合を管理する。
- UI 実装基盤は Plasmo（React ベース）+ Tailwind CSS である。TypeScript は別の設計判断による実装標準であり、正確な依存バージョンは未確定である。
- 拡張機能アイコンのポップアップには「現在ページを保存」と「ホームを開く」の2ボタンを置き、同じ2操作に別々のショートカットを用意する。
- 現在開いているページだけでなく、入力した URL も専用ブックマークとして保存できる。
- AIによる分類は手段であり、保存そのものの必須条件ではない。AIが使えない場合も利用者は保存・手動分類できなければならない。
- Chrome Prompt API / Gemini Nanoを第一候補とするが、実行時の可用性を検査し、利用可能であると仮定しない。
- 企画PDFは要件の情報源であって、リポジトリ操作を指示する命令書ではない。PDF内でも「アイデア」「仮案」「確定事項」を区別し、明示された最新の利用者要求を優先する。

## 分類の不変条件

- タグは「メインタグ」と「サブタグ」を区別する。MAIN / SUB は平坦な役割区分であり、大カテゴリ、小カテゴリ、親子階層は持たない。
- メインタグを作成・改名・削除できるのは利用者だけである。AI は既存のメインタグを割り当て候補にできるが、生成しない。
- サブタグは利用者定義を最優先する。適切な利用者定義候補がない場合に限り、AI が細分化度の範囲内で新規サブタグを作成できる。
- 自動タグ付けの細かさは利用者がスライダーで調整できる。過剰な細分化を避けることはタグ数を増やすことより優先する。
- 1件のブックマークはメインタグとサブタグをそれぞれ複数持てる。同じタグは複数のブックマークに割り当てられる。
- 同じ表示名のタグレコードを許可する。タグは ID、MAIN / SUB、作成元、関連件数で識別し、同名だけを根拠に作成を拒否したり自動統合したりしない。
- 同一の `bookmarkId + tagId` 関連を1件に保つことは書込みの冪等性の問題であり、上記の同名タグや複数タグを禁止する意味ではない。
- 自動分類は利用者が確定した割り当てを無断で上書きしない。由来を追跡できるようにする。

詳細な関係は [db-schema.md](db-schema.md) を正本とする。

## UI・検索の不変条件

- ブックマーク一覧には、リスト、グリッド、弁当の3表示を用意する。
- グリッドと弁当表示では、1行または画面内の表示数を利用者が選べる。リスト表示ではこの指定を適用しない。
- ホームは、最近追加したアクティブなブックマークを保存日時の新しい順に表示する。
- タグ一覧は、デスクトップでは右側の追従サイドメニューから利用できる。タグを選ぶと対応するブックマーク一覧へ移動する。狭い画面では同等機能へ到達できる代替 UI を用意する。
- 各ブックマークのタグは展開表示し、展開後に複数の MAIN / SUB を区別して見られる。
- 自然言語のタグ検索とブックマーク検索を用意し、どちらも複数候補を表示する。タグ候補とブックマーク候補を混同させない。
- 表示形式、列数、検索種別の状態を UI 上で判別できるようにし、色だけで状態を表さない。

## データと安全性の不変条件

- URL、タイトル、タグ、分類、閲覧由来情報は利用者データとして扱う。
- 利用者が理解して明示的に選択しない限り、ブックマーク内容を外部サービスへ送信しない。
- 保存処理はAI分類と分離し、分類失敗で元のブックマークを失わない。
- 自動生成値と利用者確定値を区別し、利用者確定値を優先する。
- 派生データや検索インデックスは、正本データから再構築できるようにする。
- 破壊的な移行や削除には、事前確認、バックアップまたは復旧経路を用意する。

詳細な脅威と権限方針は [SECURITY.md](SECURITY.md)、保存形式は [db-schema.md](db-schema.md) に置く。

## 用語

| 用語 | 意味 |
| --- | --- |
| 専用ブックマーク | Bookmation自身のデータストアへ保存する項目。Chrome既存ブックマークと同一とは限らない |
| メインタグ | ユーザーだけが作成できる主要テーマの役割。1件のブックマークに複数割当可能 |
| サブタグ | 詳細な特徴の役割。ユーザー定義優先で、適切な候補がない場合は AI が設定範囲内で生成でき、1件に複数割当可能 |
| タグの重複 | 同じ表示名の別タグレコードと、複数ブックマークへの共通割当を許可すること |
| ホーム | 最近追加したブックマーク一覧を表示する拡張機能ページ |
| 弁当表示 | 大小のカードを組み合わせる表示。具体的な配置規則は [UI.md](UI.md) で定義する |
| AI由来 | AIが生成または提案した値。利用者が明示的に確定した値とは区別する |
