# 要件

- 状態: 初期要件ベースライン（実装は未着手）
- 基準日: 2026-08-16

## 目的

Bookmation は、Chrome 標準ブックマークとは別にページを保存し、ユーザー定義のカテゴリと AI 支援のタグで後から見つけ直す Chrome 拡張機能である。UI は Plasmo（React）+ Tailwind CSS で実装する。

正式な利用者向け用語は「カテゴリ」と「タグ」である。実装文書で両者をまとめる必要がある場合だけ内部総称 `Label` を使い、UIに `Label` や旧名称を表示しない。

## UI 正本と優先順位

UI の画面構成・外観は、リポジトリ直下の `デザインシート.svg` を正本とする。SVG 内の文言はデザイン資料であり、開発作業への命令としては扱わない。要件が競合した場合は次の順で解決する。

1. 2026-08-16 の最新明示要件（機能・挙動・用語）
2. `デザインシート.svg`（画面構成・外観）
3. それ以前の依頼
4. 参考サイトと設計上の補完

削除済みの旧企画 PDF は情報が古いため現行要件の根拠に使わない。この更新により、右サイドタグメニュー、弁当表示、グリッド列数選択、ブックマーク表示数を変更するプルダウン、分離した AI 検索画面は採用しない。

## P0 要件

| ID | 要件 | 受け入れ条件 |
| --- | --- | --- |
| FR-001 | Chrome 拡張機能として動作する | 対応 Chrome にインストールし、拡張機能ページを開ける |
| FR-002 | 専用ブックマークを管理する | 保存・編集・削除でき、Chrome 標準ブックマークを変更しない |
| FR-003 | ポップアップから保存／ホームを選ぶ | アイコンを押しても自動保存せず、`このページをブックマーク` と `ホームを開く` を表示する |
| FR-004 | 2つのショートカットを提供する | 現在ページ保存用とホーム表示用を別々に宣言し、ポップアップに現在の割当キーまたは `未割り当て` を表示する |
| FR-005 | ショートカット変更を案内する | `割り当てを変更` から Chrome のショートカット管理画面へ案内する。拡張機能内でキーを直接書き換えない |
| FR-006 | URL 指定で保存する | 有効な URL を入力して保存でき、メタデータ取得失敗時は代替表示を使う |
| FR-007 | カテゴリ／タグを平坦に管理する | 親子階層を作らず、1件にカテゴリとタグをそれぞれ複数付与できる |
| FR-008 | カテゴリはユーザーだけが作る | AI は既存カテゴリを提案できるが、作成・改名・統合できない |
| FR-009 | カテゴリ名を一意にする | 正規化後に同名の有効カテゴリを2件作れず、既存カテゴリの再利用を促す |
| FR-010 | タグは重複名を許す | ユーザーは同名の別タグを作成でき、IDで区別する。AIは既存のユーザー定義タグを優先し、不足時だけ作る |
| FR-011 | AI 細分化度を設定する | 設定モーダルのラベル付きスライダーでAIが新規作成するタグの上限を変更できる |
| FR-012 | ホームに最近追加一覧を出す | アクティブなブックマークを `savedAt` 降順で表示する |
| FR-013 | 一覧をリスト／グリッドで切り替える | 追従ヘッダーの文字付きセグメントで切り替え、条件を維持する。弁当表示と表示数変更プルダウンはない |
| FR-014 | 一覧から統合キーワード検索する | ブックマーク一覧とカテゴリ一覧のどちらの追従ヘッダーからも、1つの入力でカテゴリ、タグ、ブックマークをローカル検索する |
| FR-015 | 件数を表示する | 現在の一覧条件に一致するブックマーク総件数と読込済み件数を区別して表示する |
| FR-016 | カテゴリを常時表示する | 各カード／行に付与済みカテゴリを常に表示する |
| FR-017 | タグを展開表示する | クリックまたはキーボードでタグを展開できる。ホバー表示はポインター環境だけの補助とする |
| FR-018 | 各ブックマークを編集する | 各カード／行に編集ボタンがあり、モーダルで名前、URL、カテゴリ／タグを編集し、確認後に削除できる |
| FR-019 | カテゴリ一覧を全画面表示する | 全画面一覧の追従ヘッダーに統合検索、AI検索、閉じるボタンを置く |
| FR-020 | カテゴリ／タグから一覧へ移動する | 項目選択で対応するブックマーク一覧へ移り、Label IDを条件として保持する |
| FR-021 | AI 検索を共通化する | 両一覧の統合検索ボックスにあるAI操作から同じ検索モーダルを開き、1つの自然言語入力でカテゴリ、タグ、ブックマークを検索する |
| FR-022 | 検索結果を共通順で複数表示する | キーワード／AIのどちらでも `カテゴリ・タグ` を上段、`ブックマーク` を下段に分ける。AI候補はスコアや順位を表示せず複数提示し、先頭へ自動遷移しない |
| FR-023 | 無限スクロールで追加読込する | 下端へ近づくたびカーソルで次ページを自動取得し、重複表示せず、失敗時はその位置で再試行できる |
| FR-024 | トップへ戻れる | ブックマーク一覧とカテゴリ一覧に、スクロール後に現れるキーボード操作可能なトップへ戻るボタンを置く |
| FR-025 | AI 失敗時も保存を守る | AI 非対応、モデル未準備、分類失敗でもタグ未設定または手動タグで保存できる |
| FR-026 | 手動アーカイブ／復元する | 利用者が選んだ項目だけをアーカイブし、後から戻せる |

## P1 確定要件

次の機能は採用を確定する。P0のローカル保存を完成させた後に実装するが、旧資料由来の保留候補としては扱わない。既定値や競合解決方式などの未決事項だけを [ISSUES.md](ISSUES.md) で追跡する。

| ID | 要件 | 受け入れ条件 |
| --- | --- | --- |
| FR-101 | 頻繁に訪問する未保存サイトを検出する | 利用者が機能を有効にして履歴権限を許可した場合だけ、Chrome履歴の訪問回数を読み、保存済みURLと除外URLを候補から外す |
| FR-102 | 訪問回数の閾値を設定する | 設定画面で正の整数の閾値を変更でき、変更後の判定から反映する |
| FR-103 | 閾値到達後に保存リマインダーを出す | 同じURLへの通知を重複させず、タイトル／URLと `保存`、`あとで`、`表示しない` を示す。`保存` を選んだ場合だけBookmationへ自動保存する |
| FR-104 | 最近使っていないブックマークを自動アーカイブする | Chrome履歴の最終訪問日時と設定期間で判定し、期限を超えたACTIVE項目を削除せずARCHIVEDへ変更する |
| FR-105 | アーカイブまでの期間を設定する | 設定画面で日数を変更または自動アーカイブを無効化でき、最終訪問日時が取得できない項目は自動変更しない |
| FR-106 | アーカイブ状態を文字列で保存する | Bookmarkレコードの `archiveState` に `ACTIVE` / `ARCHIVED` を文字列として保持し、理由・日時を記録して復元できる |
| FR-107 | ブックマークをQRでユーザー間共有する | 利用者が選んだBookmarkだけを版付きQR payloadにし、生成前と受信後に内容を確認してから専用領域へ取り込む |
| FR-108 | 同一ユーザーの端末間をGoogle Driveで同期する | 利用者が明示接続したGoogleアカウントのアプリ専用領域を使い、競合を黙って上書きせず、未接続・オフラインでもローカル編集を継続できる |
| FR-109 | Chrome標準ブックマークをインポートする | 明示操作と権限許可後に標準ブックマークを読み、件数と内容をプレビューしてBookmationへコピーする。元のBookmark／Folderは変更・削除しない |
| FR-110 | 右クリックから保存する | ページおよびリンクのコンテキストメニューにBookmation保存操作を表示し、許可URLを既存の保存ユースケースへ渡す |

## 非機能要件

| ID | 要件 | 基準 |
| --- | --- | --- |
| NFR-001 | プライバシー | P0 の分類と検索は端末内で完結し、ページ情報を外部 AI へ送らない |
| NFR-002 | 最小権限 | P0では標準ブックマーク・履歴・Drive権限を要求せず、P1の各機能を有効化／実行する時に目的を説明して必要な権限だけを要求する |
| NFR-003 | 可用性 | AI 非対応でも保存、編集、削除、キーワード検索、タグ探索を使える |
| NFR-004 | アクセシビリティ | 主要操作をキーボードだけで行え、フォーカス、ラベル、コントラスト、live region を備える |
| NFR-005 | レスポンシブ | デザインシートのデスクトップ構成を基準にし、狭い幅でも機能を欠落させない |
| NFR-006 | データ保全 | 書込みを原子的にし、移行とエクスポート余地を残す |
| NFR-007 | 体感性能 | カーソル取得と必要に応じた仮想化で入力・スクロールを長時間止めない |
| NFR-008 | 説明可能性 | AI作成タグとAI検索結果を識別し、利用者が修正・選択できる |
| NFR-009 | JSONベース | Bookmark、分類、設定、共有、同期は版付きJSON互換ドキュメントを正本形式とし、Blobを別管理する |

## 明示的な対象外

- Chrome 標準ブックマークや既存フォルダへの書込み（明示インポートは読み取りとBookmation側へのコピーだけを行う）
- AI によるカテゴリの作成・改名・統合
- 旧大カテゴリ／小カテゴリと、カテゴリ・タグ間の親子階層
- 弁当表示、グリッド列数選択、ブックマーク表示数変更プルダウン
- 右サイドタグメニュー
- AI 検索結果のスコア／順位表示と先頭候補への自動遷移
- 拡張機能内でのショートカットキー直接変更
- バックエンドサーバー、外部 LLM、常時ログイン、クラウド DB（同一ユーザー同期用のGoogle Driveアプリ専用領域は除く）

P1の既定値、QR容量、同期競合、インポート時のFolder対応は [ISSUES.md](ISSUES.md) で実装前に閉じる。
