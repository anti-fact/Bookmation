# UI 設計

- 状態: 実装前の設計基準
- 更新日: 2026-08-17
- UI 技術: Plasmo（React）+ Tailwind CSS
- UI 正本: リポジトリ直下の `デザインシート.svg`
- 関連: [要件](./REQUIREMENTS.md) / [設計](./DESIGN.md) / [フロントエンド](./FRONTEND.md)

## 正本の読み方

更新済みデザインシートのデスクトップ版グリッド／リスト、全画面カテゴリ・タグ一覧、管理モード、作成・編集モーダル、設定のサイドナビ、訪問リマインダー、AIポップアップ、初回ホームを配置とトーンの基準とする。機能、用語、入力方式が競合するときは最新の明示要件を優先する。

## 分類の共通ルール

- カテゴリを親、タグを子とする固定2階層とし、タグは有効な親カテゴリを必ず1件持つ。
- カテゴリはユーザーだけが作成し、正規化後の名前をカテゴリ全体で重複させない。
- タグはユーザーまたはAIが作成できるが、正規化後の名前を親カテゴリにかかわらずタグ全体で重複させない。
- カテゴリ名とタグ名は別の名前空間で判定するため、カテゴリとタグの間では同じ表示名を利用できる。
- 1件のブックマークは複数カテゴリと複数タグを持てる。ただしタグを付ける場合はその親カテゴリも付ける。
- カテゴリをブックマークから外すときは、同時に外れる選択中の子タグを入力欄内へ明示し、同じdraftからまとめて解除する。タグ自体の全体削除は行わない。
- クリック／キーボードを必須経路とし、hoverだけに操作や情報を置かない。

| route / state | 内容 |
| --- | --- |
| `#/welcome` | インストール直後に1回だけ開く初回ホーム |
| `#/home` | 最近追加したブックマーク |
| `#/bookmarks?category=<id>` | カテゴリで絞ったブックマーク |
| `#/bookmarks?tag=<id>` | タグで絞ったブックマーク |
| `#/search?q=<query>` | キーワード検索の全画面結果 |
| `#/labels` | 全画面カテゴリ・タグ一覧 |
| `#/settings/general` | 一般設定 |
| `#/settings/archive` | アーカイブ管理 |
| `#/settings/share` | Drive同期・QR共有／取込 |
| `editBookmark=<id>` | ブックマーク編集モーダル |

キーワードは戻る／再読込に耐えるよう検索routeへ保持する。AI会話、未保存の編集draft、ページカーソルはURLへ残さない。モーダル／ポップアップは初期フォーカス、Esc、閉じた後のフォーカス復帰を備える。

## インストール直後の初回ホーム

`chrome.runtime.onInstalled` の `reason === "install"` のときだけ `#/welcome` を開く。ロゴ、短い説明、`ここからはじめる` を表示し、押下後に必要最小限の初期設定を経て `#/home` へ移る。更新時や通常起動時には再表示しない。途中で閉じても次回ホームから再開できる導線を残す。

## 拡張機能ポップアップ

次の2操作を同じ順で表示する。

1. `このページをブックマーク`
2. `Bookmation ホームを開く`

各操作の右側に `chrome.commands.getAll()` から得た現在のキー、または `未割り当て` を表示する。`割り当てを変更` はChromeのショートカット管理画面への案内であり、拡張機能内でキーを変更しない。ポップアップを開いただけでは保存しない。

## 共通ヘッダーと検索

ブックマーク一覧とカテゴリ・タグ一覧の検索ボックスは同じ `SearchBox` を使う。文字入力中はローカルのキーワード検索をdebounceし、Google検索の候補表示に近いcomboboxを入力直下へ開く。

- カテゴリ・タグとブックマークを横断し、一致度の高い候補を合計8件まで表示する。
- 候補内は `カテゴリ・タグ` を上、`ブックマーク` を下にする。
- 一致箇所、種別、親カテゴリまたはURLを補足し、表示スコアは出さない。
- 上下キー、Enter、Esc、IME変換、screen readerに対応する。
- 候補選択は対象へ直接移動する。Enterまたは検索ボタンは `#/search?q=...` へフルページ遷移する。

検索結果画面はカテゴリ・タグ結果を上段、ブックマーク結果を下段にし、それぞれ0件、読込中、失敗、終端を表示する。入力中候補だけを8件に制限し、全画面結果はカーソルで続きを読み込める。

## AI自然言語検索・機能案内ポップアップ

ロボット／AIボタンから、デザインシートの右下に重なる `AiAgentPopup` を開く。入力、送信状態、AI応答、候補、再試行を同じポップアップ内で確認でき、自然言語入力のために別ページへ移動しない。

AIは次の2種類を受け付ける。

1. 保存済みデータを探す依頼。カテゴリ・タグ候補を先、ブックマーク候補を後に提示する。
2. Bookmationの機能、設定、保存、検索、分類、共有、同期、アーカイブ、ショートカット等の使い方に関する質問。

機能説明は版管理された製品ヘルプを根拠にし、未実装機能を利用可能と断定しない。一般Web検索や無関係な雑談を製品機能として扱わない。AI応答から削除、共有、設定変更等を直接実行せず、必要な画面への案内までに留める。AI利用不可時もキーワード検索と静的ヘルプは利用できる。

## ブックマーク一覧

追従ヘッダーに検索、AI、総件数／読込済み件数、`リスト / グリッド` セグメント、カテゴリ・タグ一覧、設定への導線を置く。弁当表示、列数選択、表示数変更プルダウンは置かない。

各カード／行はタイトル、URLまたはドメイン、保存日時、画像／代替面、カテゴリ、タグ件数、編集ボタンを持つ。カテゴリは常時表示し、タグはクリック／Enter／Spaceで展開する。hover tooltipは補助に限る。

下端sentinelで次ページを1回だけ読み込み、重複要求を防ぐ。一定距離後に `トップへ戻る` を表示し、先頭見出しへフォーカス付きで戻す。

## ブックマーク編集モーダル

名前とURLに加え、カテゴリとタグを別々のcomboboxで編集する。

- `カテゴリを編集`: 既存カテゴリを入力検索し、一致度の高い候補を8件まで表示して複数選択する。
- `タグを編集`: 既存タグを入力検索し、親カテゴリ名付きで8件まで表示して複数選択する。
- タグ選択時は親カテゴリを同じdraftへ追加する。親カテゴリを外す場合は同時に外れる子タグを示し、そのdraftからまとめて解除する。
- 各説明ラベルの横に `＋新規作成` を置く。

`＋新規作成` はモーダルを重ねず、同じモーダル内のサイドビューへ切り替える。カテゴリ側からはカテゴリ、タグ側からはタグを固定して作成し、戻ると編集draftと検索語を復元する。作成成功した項目はdraftへ追加する。

`保存する` と `削除する` を置く。削除確認画面は挟まず即時に論理削除し、削除後の取り消し操作や利用者向け復元経路は表示しない。削除commandが失敗した場合は論理削除せず、モーダルと入力を保持してエラーを表示する。

## 全画面カテゴリ・タグ一覧

更新済みデザインシートの水色の全画面表示を採用する。追従ヘッダーには統合検索、AI検索、`新規作成` プルダウン、`管理`、`閉じる` を置く。カテゴリは黒いリボン、直属の子タグはその下の枠線付きチップで表示し、親子関係を視覚とアクセシブル名の両方で表す。

通常モードではカテゴリ／タグ選択で対応ブックマーク一覧へ移動する。`管理` を押すと管理モードへ切り替え、ボタンを選択状態にし、`管理中: 編集する項目を選択` を通知する。管理モード中にカテゴリリボンまたはタグチップを選ぶと編集モーダルを開く。鉛筆アイコンはhover／focus時だけ表示してよいが、管理モードとクリック操作だけでも到達できる。

無限スクロール、失敗位置での再試行、トップへ戻る、閉じた後の検索条件とスクロール位置復元を備える。

## カテゴリ・タグの作成

一覧ヘッダーの `新規作成` プルダウンから `カテゴリ作成` または `タグ作成` を選び、共通モーダルを開く。選択した種類を見出しへ明示する。

- カテゴリ作成は名前を入力し、正規化名が有効または論理削除中の既存カテゴリと一致すれば作成を拒否する。有効なら元の入力画面で既存項目を選択し、論理削除中なら別名を入力するか物理GC完了を待つよう案内する。
- タグ作成は名前と親カテゴリを必須とする。正規化名が有効または論理削除中の既存タグと一致すれば、親カテゴリが異なっても作成を拒否する。既存タグの状態と親カテゴリを示し、有効なら元の入力画面で既存項目を選択し、論理削除中なら別名を入力するか物理GC完了を待つよう案内する。
- 作成画面は新規作成専用で、既存項目をブックマークへ追加する機能を持たない。
- 作成後もモーダルを閉じず、入力をクリアして続けて作成できる。今回作成した項目と成功／失敗を表示し、利用者が `閉じる` を押すまで維持する。

## カテゴリ・タグの編集と削除

編集モーダルは種類を変更不可とし、名前、親カテゴリ（タグのみ）、作成元、利用件数を表示する。タグの親カテゴリは現行P0では読取専用とし、変更UIは [ISSUE-019](./ISSUES.md) の決定後に追加する。カテゴリとタグの改名はいずれも、それぞれの名前空間で正規化名の一意性を検証する。

削除確認画面は表示しない。削除ボタン押下で即時に論理削除し、関連解除を同じ処理で行う。削除後の取り消し操作や利用者向け復元経路は表示しない。子タグが残るカテゴリは削除できず、現行P0では対象タグを個別削除するかカテゴリ削除を中止するための一覧を出す。親変更は [ISSUE-019](./ISSUES.md) の決定前には案内せず、連鎖削除や自動統合もしない。

## 設定画面

歯車からサイドナビ付き全画面設定を開き、`一般`、`アーカイブ`、`共有` を切り替える。

### 一般

- `訪問回数の閾値`: 正の整数を入力する数値フォーム。単位 `回` を常時表示する。
- `自動ブックマークのリマインダー`: 有効／無効のトグル。オンにする操作で履歴・通知権限の目的を説明する。
- `アーカイブ化の閾値`: 正の整数の日数入力。単位 `日` を常時表示する。初めて自動判定を開始する時は履歴権限の目的を説明し、拒否時は値を失わず `権限待ち` として自動判定を停止する。独立した有効／無効トグルは置かない。
- `AIタグの細分化`: 0〜4の離散スライダー。現在値と効果を文章でも表示する。

| 値 | 表示 | 1回の分類でAIが新規作成できるタグ上限 |
| --- | --- | --- |
| 0 | 既存タグのみ | 0 |
| 1 | 粗い | 1 |
| 2 | 標準 | 2 |
| 3 | 細かい | 4 |
| 4 | 最も細かい | 6 |

値0でも既存カテゴリ・既存タグの自動選択と付与は行う。停止するのはAIによる新規タグ作成だけである。設定変更は今後の分類へ適用し、既存データを自動再分類しない。

### アーカイブ

アーカイブ済みブックマークをリスト表示し、ページ名、URL、カテゴリ、タグ、選択チェックボックスを示す。個別または複数選択して復元でき、成功／失敗を項目ごとに返す。アーカイブの利用者データはページ名、URL、カテゴリ、タグだけを保持し、画像、説明、訪問履歴、検索派生データは保持しない。ID、schemaVersion、アーカイブ日時等の内部運用メタデータは表示内容と分離する。

### 共有

Drive領域では接続に使うGoogleアカウントを選ぶ。同一アカウントの端末同期は共有不可の `appDataFolder`、所有権／共有権限のある別アカウントとの共有は通常Drive fileを使う別機能として表示する。接続中アカウント、対象ファイル、最終同期、未同期、競合、権限不足を表示する。

QR共有ではカテゴリ別、タグ別、個別ブックマークの入口を設け、検索とチェックボックスで共有対象を選ぶ。選択はブックマークIDへ展開して重複を除き、内容と容量を確認してからQRコードを生成する。QR取込はカメラまたは画像から読み取り、形式、容量、重複、カテゴリ・タグ構造を検証し、プレビュー後に取り込む。

## 訪問リマインダー

設定が有効で、訪問閾値へ達した未保存URLだけに表示する。タイトル／URL、`はい`、`いいえ`、`次回から表示しない` チェックボックスを示し、`はい` を押すまで保存しない。

`次回から表示しない` はその正規化URLの今後の候補を抑止し、設定全体をオフにはしない。保存済みURL、抑止済みURL、同時処理中URLには重複表示しない。

## 標準Bookmark取込と右クリック保存

Chrome標準Bookmark取込は権限説明、folder別件数、プレビュー、進捗、成功／skip／失敗を示し、元データを変更しない。context menuはページとリンクを共通保存ユースケースへ渡す。

## テスト用Webプレビュー

welcome、popup、一覧、検索ページ、AIポップアップ、カテゴリ・タグ一覧の通常／管理、作成連続操作、ブックマーク編集サイドビュー、設定3区分、リマインダー、アーカイブ復元、Drive／QRを本番と同じReact componentとTailwind tokenで通常Webページ表示する。

fake Adapterと版管理fixtureで、0／8／9件候補、カテゴリ／タグの同名作成拒否、親カテゴリ欠損、細分化0〜4、権限拒否、抑止済みURL、即時論理削除、子タグが残るカテゴリの削除拒否、QR破損、Drive競合、200%拡大等を選べるようにする。Webプレビュー後にAIエージェントが実拡張をPlaywrightで確認し、最後に人間が同じbuildを受け入れる。

## 主要な受け入れ確認

- インストール直後だけ初回ホームが開く。
- 検索入力中に最大8候補が出て、確定検索は全画面へ移る。
- AIポップアップ内で入力と応答を確認でき、保存データ検索と製品機能の質問に対応する。
- ブックマーク編集でカテゴリとタグを別々に選択し、各サイドビューから新規作成できる。
- カテゴリ親とタグ子の整合を崩す操作が保存されない。
- カテゴリ同士、タグ同士の正規化名が重複せず、タグは親カテゴリが異なっても同名作成できない。
- 作成モーダルは閉じるまで連続作成でき、管理モードから編集できる。
- 削除確認画面を出さず即時に論理削除し、削除後の取り消し操作が表示されない。
- 訪問回数とアーカイブ日数は数値入力、AI細分化だけが0〜4スライダーである。
- 細分化0でも既存タグの自動付与が動作する。
- リマインダーを設定で無効化でき、URL単位の `次回から表示しない` が効く。
- 設定からアーカイブを複数選択復元でき、Drive／QR共有・QR取込を開始できる。
- 弁当表示、表示数変更、右サイドタグメニューが表示されない。
