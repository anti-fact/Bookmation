## 正本の読み方

デザインシートのデスクトップ版グリッド／リスト、全画面一覧、ブックマーク編集モーダル、追従ヘッダー、件数、編集・トップへ戻る操作を画面構成の基準とする。SVG内の旧用語は現行の「カテゴリ」「タグ」へ読み替える。明示要件と見た目が競合するときは、挙動と用語は [REQUIREMENTS.md](./REQUIREMENTS.md)、配置・トーンはデザインシートを優先する。

## 共通ルール

- カテゴリはユーザーだけが作成する。同じ正規化名のカテゴリは1件だけとする。
- タグは同名の別IDを許す。AIはユーザー定義タグを優先し、不足時だけ新規作成する。
- 1件のブックマークにカテゴリ／タグをそれぞれ複数付与できる。
- 両一覧に同じ統合検索ボックスを置き、キーワード／AIのどちらもカテゴリ、タグ、ブックマークを対象にする。
- クリック／キーボードを必須操作とし、ホバーだけに情報を置かない。

## 拡張機能ポップアップ

次の2操作を常に同じ順で表示する。

1. `このページをブックマーク`
2. `Bookmation ホームを開く`

各操作の右側に、`chrome.commands.getAll()` から取得した現在のキーを keycap 表現で表示する。空文字なら `未割り当て` と表示する。下部の `割り当てを変更` は `chrome://extensions/shortcuts` で利用者が変更することを案内する。Chrome の制約で直接開けない場合は URL と開き方を選択可能なテキストで示す。拡張機能自身がキーを変更したように表示しない。

保存可能、保存中、保存済み、既存、保存不可、失敗を区別する。ポップアップを開いただけでは保存しない。

## 画面とオーバーレイ

| route / state | 内容 |
| --- | --- |
| `#/home` | 最近追加したブックマーク |
| `#/bookmarks?label=<labelId>` | 選択したカテゴリ／タグに対応するブックマーク |
| `#/labels` | 全画面カテゴリ一覧。閉じると直前画面・スクロール位置へ戻る |
| `#/archive` | アーカイブ済みブックマーク一覧と復元 |
| `#/add-url` | URL 指定保存モーダル |
| `editBookmark=<id>` | ブックマーク編集モーダル |
| `settings=open` | 設定モーダル |
| `aiSearch=open` | 共通 AI 検索モーダル |
| `shareQr=<id...>` | QR共有の内容確認と生成 |
| `importQr=open` | QR読取結果の確認と取込 |
| `importChrome=open` | Chrome標準Bookmarkのプレビューと取込 |

検索文、AI 入力、ページカーソルは URL に残さない。モーダルは背景を不活性化し、初期フォーカス、フォーカストラップ、Esc、閉じた後のフォーカス復帰を備える。

## ブックマーク一覧

デザインシートに合わせ、上部にロゴ／主要導線、その下に一覧用の追従ヘッダーを置く。ヘッダーはスクロール中も表示し、次を含む。

- カテゴリ、タグ、ブックマークを対象にする統合検索ボックス
- 同じ入力を自然言語として検索するAIアイコンボタン
- `リスト / グリッド` の文字付きセグメントコントロール
- 現在条件の総件数と読込済み件数（例: `120件中 40件を表示`）
- 全画面カテゴリ一覧を開く操作と設定モーダルを開く操作

弁当表示、列数選択、ブックマーク表示数を変更するプルダウンは置かない。グリッド列数は CSS の responsive rule、1回の取得件数は実装側のページング設定で決め、利用者向け設定にしない。表示を切り替えても検索語、選択タグ、読込済み範囲、可能な範囲のスクロール位置を維持する。

### カード／行

リストとグリッドで情報の意味を共通にする。

- タイトル、URL またはドメイン、保存日時、画像／代替面
- 付与済みカテゴリを常に文字ラベルで表示
- タグ件数と開閉ボタン
- すべての項目に名前のある `編集` ボタン
- 元ページを開く、再分類、アーカイブ等の補助操作

タグは閉じた状態を既定とし、クリック／Enter／Spaceで展開する。`aria-expanded` と `aria-controls` を付ける。ポインター環境のhover tooltipは同じ内容のプレビューとして追加できるが、クリック展開の代替にはしない。カテゴリはタグの開閉にかかわらず常時表示する。

### 無限スクロールとトップへ戻る

下端 sentinel が viewport に近づくたび次カーソルを1回だけ読み込む。読込中、終端、失敗を区別し、失敗位置には再試行を置く。追加件数は live region で通知し、フォーカスを移動しない。キーボードで sentinel に到達した場合も同じ取得を開始する。

一定距離をスクロールしたら `トップへ戻る` ボタンを表示する。押すと一覧先頭の見出しへフォーカス付きで戻し、`prefers-reduced-motion` では滑らかスクロールを強制しない。

## 全画面カテゴリ一覧

右サイドメニューは使わず、デザインシートの全画面表示を採用する。追従ヘッダーには次を置く。

- カテゴリ、タグ、ブックマークを対象にする統合検索ボックス
- 同じ入力を自然言語として検索するAIアイコンボタン
- 名前付きの `カテゴリ一覧を閉じる` ボタン

本文はカテゴリとタグを視覚的に区別する。カテゴリ作成時は正規化名が一致する既存カテゴリを表示して再利用させ、同名カテゴリは作れない。タグ作成時は既存候補を先に出すが、利用者は同名の別タグを明示して作成できる。項目を選ぶと `#/bookmarks?label=<labelId>` へ移る。

カテゴリ一覧にも無限スクロールと `トップへ戻る` を適用する。閉じる操作では直前のブックマーク画面、検索条件、表示形式、スクロール位置を復元する。

## 共通 AI 検索モーダル

ブックマーク一覧とカテゴリ一覧の検索ボックス内AIアイコンから同じモーダルを開く。デザイン上はアイコン左へのflyoutではなく、入力・候補・説明を安全に収められるモーダルを正規形とする。

1つの自然言語フォームでカテゴリ、タグ、ブックマークを同時に探す。結果は必ず上段の `カテゴリ・タグ`、下段の `ブックマーク` の順にする。可能性が高い候補集合だけを複数表示するが、順位番号、スコア、`最適` 表現は出さず、先頭へ自動遷移しない。同じ候補集合は種類ごとの安定した中立順で表示する。

カテゴリ／タグ候補には名前、種別、利用件数、短い一致理由を表示する。同名タグはIDにひも付く補足情報で区別する。ブックマーク候補にはタイトル、ドメイン、カテゴリ、タグ件数、短い一致理由を表示する。AIが使えない場合は、ローカル文字列検索への縮退であることを明示する。

## 統合キーワード検索

両一覧の検索ボックスは同一コンポーネントと同一query契約を使う。入力中はローカル検索を行い、結果popoverまたはmodalに `カテゴリ・タグ` を上、`ブックマーク` を下の順で表示する。現在開いている一覧の種類で対象を狭めない。カテゴリ／タグ候補を選ぶと分類別Bookmark一覧、Bookmark候補を選ぶと対象Bookmarkまたは元ページへ移動する。0件時も2グループの対象を明示する。

IME 変換中は送信せず、処理中、モデル準備中、候補あり、0件、失敗を区別する。候補はキーボードで選択できる。

## ブックマーク編集モーダル

各カード／行の編集ボタンから開き、次を編集できる。

- 名前
- URL（`http` / `https`、正規化後の値を確認）
- 複数のカテゴリ／タグの追加・解除

`保存`、`キャンセル`、`ブックマークを削除` を置く。削除は破壊的操作として確認ダイアログを挟み、対象名を明示する。保存失敗時は入力を保持する。URL 変更時は勝手に外部ページを開かない。

## 設定モーダル

デザインシートの歯車から開き、次を変更できる。

- `AIが作るタグの細かさ`: 1〜5の離散スライダー
- `よく訪問するサイトを知らせる`: 有効／無効と正の整数の訪問回数閾値
- `使っていないブックマークを自動アーカイブ`: 有効／無効と正の日数
- `Google Drive同期`: 接続、最終同期状態、再同期、切断

| 値 | ラベル | 1回の分類で新規作成できるタグ上限 |
| --- | --- | --- |
| 1 | 既存のみ | 0 |
| 2 | 粗い | 1 |
| 3 | 標準 | 2 |
| 4 | 細かい | 4 |
| 5 | 詳細 | 6 |

現在値の効果を文章で表示する。変更は今後の分類だけに適用し、既存ブックマークを自動再分類しない。カテゴリはどの値でもAIが作成しない。履歴を使う2機能は、有効化前に用途と範囲を説明して権限を要求し、拒否時はオフのままにする。

## 訪問リマインダーとアーカイブ

訪問閾値へ達した未保存サイトは、システム通知またはホーム内リマインダーでタイトルとURLを示し、`保存`、`あとで`、`表示しない` を提供する。通知だけで保存済みにせず、`保存` 選択後に通常の保存完了／重複状態を表示する。

自動アーカイブは実行結果の件数を通知し、アーカイブ一覧から復元できる。最終訪問日時を表示できない項目は自動変更しない。ARCHIVEDは削除済みと表現しない。

## QR共有・Drive同期・標準Bookmark取込

- QR共有は選択件数、タイトル、URL、カテゴリ／タグ、payloadサイズを生成前に確認し、容量超過時は生成しない。
- QR取込は不明形式や過大payloadを拒否し、内容と重複候補を確認してから保存する。
- Drive同期は接続中アカウント、最終同期、未同期件数、競合、エラーを設定画面に表示する。QRを同一ユーザー同期には使わない。
- 標準Bookmark取込は権限説明、folder別件数のpreview、実行、進捗、成功／skip／失敗内訳を示す。元のChrome Bookmarkを変更しないことを明記する。
- 右クリックでは `このページをBookmationに保存` と `このリンクをBookmationに保存` を対象contextに応じて表示し、保存結果を通知する。

## キーワード検索との区別

- 両一覧のキーワード検索は、カテゴリ／タグ名とBookmarkのタイトル、URL、付与分類を同時にローカル照合する。
- 自然文の意味検索は同じ入力を引き継いだAIモーダルで行う。
- どちらもカテゴリ・タグを上、ブックマークを下に表示する。

0件時は検索種別と解除操作を示す。ローカル検索は AI 非対応・オフラインでも動く。

## 主要な受け入れ確認

- ポップアップの2操作に現在のショートカット、未割当状態、変更案内が表示される。
- 両一覧の追従ヘッダーで統合検索を使え、ブックマーク一覧では件数とリスト／グリッドも操作できる。
- カテゴリは常時見え、タグはクリック／キーボードで展開できる。
- すべてのカード／行から編集モーダルを開き、名前、URL、タグを保存し、確認後に削除できる。
- 全画面カテゴリ一覧を開閉でき、追従する統合検索とトップへ戻る操作がある。
- どちらの一覧からもカテゴリ、タグ、ブックマークを検索でき、カテゴリ・タグ結果が上、ブックマーク結果が下に表示される。
- 下端へスクロールするたび次ページが重複なく読み込まれる。
- 弁当表示、列数選択、表示数変更プルダウン、右サイドタグメニューが表示されない。
