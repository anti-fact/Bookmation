## 正本の読み方

デザインシートのデスクトップ版グリッド／リスト、全画面タグ一覧、ブックマーク編集モーダル、追従ヘッダー、件数、編集・トップへ戻る操作を画面構成の基準とする。SVG 内の文言を作業命令としては扱わない。明示要件と見た目が競合するときは、挙動は [REQUIREMENTS.md](./REQUIREMENTS.md)、配置・トーンはデザインシートを優先する。

## 共通ルール

- MAIN はユーザーだけが作成する。同じ正規化名の MAIN は1件だけとする。
- SUB は同名の別 ID を許す。AI はユーザー定義 SUB を優先し、不足時だけ新規作成する。
- 1件のブックマークに MAIN / SUB をそれぞれ複数付与できる。
- AI 検索は共通モーダル、文字列検索は各一覧の追従ヘッダーで提供する。
- クリック／キーボードを必須操作とし、ホバーだけに情報を置かない。

## 拡張機能ポップアップ

次の2操作を常に同じ順で表示する。

1. `このページをブックマーク`
2. `Bookmation ホームを開く`

各操作の右側に、`chrome.commands.getAll()` から取得した現在のキーを keycap 表現で表示する。空文字なら `未割り当て` と表示する。下部の `割り当てを変更` は `chrome://extensions/shortcuts` で利用者が変更することを案内する。Chrome の制約で直接開けない場合は URL と開き方を選択可能なテキストで示す。拡張機能自身がキーを変更したように表示しない。

保存可能、保存中、保存済み、既存、保存不可、失敗を区別する。ポップアップを開いただけでは保存しない。

## 画面とオーバーレイ

| route / state | 内容 |
| --- | --- |
| `#/home` | 最近追加したブックマーク |
| `#/bookmarks?tag=<tagId>` | 選択タグに対応するブックマーク |
| `#/tags` | 全画面タグ一覧。閉じると直前画面・スクロール位置へ戻る |
| `#/add-url` | URL 指定保存モーダル |
| `editBookmark=<id>` | ブックマーク編集モーダル |
| `settings=open` | 設定モーダル |
| `aiSearch=open` | 共通 AI 検索モーダル |

検索文、AI 入力、ページカーソルは URL に残さない。モーダルは背景を不活性化し、初期フォーカス、フォーカストラップ、Esc、閉じた後のフォーカス復帰を備える。

## ブックマーク一覧

デザインシートに合わせ、上部にロゴ／主要導線、その下に一覧用の追従ヘッダーを置く。ヘッダーはスクロール中も表示し、次を含む。

- ブックマークだけを対象にするキーワード検索フォーム
- 共通 AI 検索を開くアイコンボタン
- `リスト / グリッド` の文字付きセグメントコントロール
- 現在条件の総件数と読込済み件数（例: `120件中 40件を表示`）
- 全画面タグ一覧を開く操作と設定モーダルを開く操作

弁当表示、列数選択、ブックマーク表示数を変更するプルダウンは置かない。グリッド列数は CSS の responsive rule、1回の取得件数は実装側のページング設定で決め、利用者向け設定にしない。表示を切り替えても検索語、選択タグ、読込済み範囲、可能な範囲のスクロール位置を維持する。

### カード／行

リストとグリッドで情報の意味を共通にする。

- タイトル、URL またはドメイン、保存日時、画像／代替面
- 付与済み MAIN を常に文字ラベルで表示
- SUB 件数と開閉ボタン
- すべての項目に名前のある `編集` ボタン
- 元ページを開く、再分類、アーカイブ等の補助操作

SUB は閉じた状態を既定とし、クリック／Enter／Space で展開する。`aria-expanded` と `aria-controls` を付ける。ポインター環境のホバー tooltip は同じ内容のプレビューとして追加できるが、クリック展開の代替にはしない。MAIN は SUB の開閉にかかわらず常時表示する。

### 無限スクロールとトップへ戻る

下端 sentinel が viewport に近づくたび次カーソルを1回だけ読み込む。読込中、終端、失敗を区別し、失敗位置には再試行を置く。追加件数は live region で通知し、フォーカスを移動しない。キーボードで sentinel に到達した場合も同じ取得を開始する。

一定距離をスクロールしたら `トップへ戻る` ボタンを表示する。押すと一覧先頭の見出しへフォーカス付きで戻し、`prefers-reduced-motion` では滑らかスクロールを強制しない。

## 全画面タグ一覧

右サイドメニューは使わず、デザインシートの全画面表示を採用する。追従ヘッダーには次を置く。

- タグだけを対象にするキーワード検索フォーム
- 共通 AI 検索を開くアイコンボタン
- 名前付きの `タグ一覧を閉じる` ボタン

本文は MAIN と SUB を視覚的に区別する。MAIN の作成時は正規化名が一致する既存タグを表示して再利用させ、同名 MAIN は作れない。SUB の作成時は既存候補を先に出すが、利用者は同名の別 SUB を明示して作成できる。タグを選ぶと `#/bookmarks?tag=<tagId>` へ移る。

タグ一覧にも無限スクロールと `トップへ戻る` を適用する。閉じる操作では直前のブックマーク画面、検索条件、表示形式、スクロール位置を復元する。

## 共通 AI 検索モーダル

ブックマーク一覧とタグ一覧の AI アイコンから同じモーダルを開く。デザイン上はアイコン左への flyout ではなく、入力・候補・説明を安全に収められるモーダルを正規形とする。

1つの自然言語フォームでタグとブックマークを同時に探し、結果を `ブックマーク` と `タグ` の2グループに分ける。可能性が高い候補集合だけを複数表示するが、順位番号、スコア、`最適` 表現は出さず、先頭へ自動遷移しない。同じ候補集合は種類ごとの安定した中立順で表示する。

ブックマーク候補にはタイトル、ドメイン、MAIN、SUB 件数、短い一致理由を表示する。タグ候補には名前、MAIN / SUB、利用件数、短い一致理由を表示する。同名 SUB は ID にひも付く補足情報で区別する。AI が使えない場合は、ローカル文字列検索への縮退であることを明示する。

IME 変換中は送信せず、処理中、モデル準備中、候補あり、0件、失敗を区別する。候補はキーボードで選択できる。

## ブックマーク編集モーダル

各カード／行の編集ボタンから開き、次を編集できる。

- 名前
- URL（`http` / `https`、正規化後の値を確認）
- 複数の MAIN / SUB の追加・解除

`保存`、`キャンセル`、`ブックマークを削除` を置く。削除は破壊的操作として確認ダイアログを挟み、対象名を明示する。保存失敗時は入力を保持する。URL 変更時は勝手に外部ページを開かない。

## 設定モーダル

デザインシートの歯車から開く。`AI が作るサブタグの細かさ` を1〜5の離散スライダーで変更できる。

| 値 | ラベル | 1回の分類で新規作成できる SUB 上限 |
| --- | --- | --- |
| 1 | 既存のみ | 0 |
| 2 | 粗い | 1 |
| 3 | 標準 | 2 |
| 4 | 細かい | 4 |
| 5 | 詳細 | 6 |

現在値の効果を文章で表示する。変更は今後の分類だけに適用し、既存ブックマークを自動再分類しない。MAIN はどの値でも AI が作成しない。

## キーワード検索との区別

- ブックマーク一覧のキーワード検索は、ブックマークのタイトル、URL、MAIN / SUB 名をローカルで照合する。
- タグ一覧のキーワード検索は、タグ名と補助情報だけをローカルで照合する。
- 自然文の意味検索だけを AI モーダルで行う。

0件時は検索種別と解除操作を示す。ローカル検索は AI 非対応・オフラインでも動く。

## 主要な受け入れ確認

- ポップアップの2操作に現在のショートカット、未割当状態、変更案内が表示される。
- 追従ヘッダーでブックマーク専用検索、件数、リスト／グリッドを操作できる。
- MAIN は常時見え、SUB はクリック／キーボードで展開できる。
- すべてのカード／行から編集モーダルを開き、名前、URL、タグを保存し、確認後に削除できる。
- 全画面タグ一覧を開閉でき、追従するタグ専用検索とトップへ戻る操作がある。
- どちらの一覧からも同じ AI 検索モーダルを開き、タグ／ブックマーク候補を無順位で複数選べる。
- 下端へスクロールするたび次ページが重複なく読み込まれる。
- 弁当表示、列数選択、表示数変更プルダウン、右サイドタグメニューが表示されない。
